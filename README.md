# 证券除权复权与持仓对账

券商数据校验员使用本工具完成：归一公司行动与成交持仓文件，复算除权因子和股数现金。

## 业务

除权参考价=(前收盘-每股现金+配股价×配股比例)/(1+送转比例+配股比例)，按登记日判定权益，零碎股单列。七个核算模块：行动接收、证券映射、权益登记、除权因子、持仓重算、现金对账、修订回放；另有撤销冲减用于已复核批次的追加式撤销。模块独立API及页面入口见docs/API.md。样例中包含真实常见脏数据，原因码和原始行号在隔离面板及证据文件中可复核。

## 启动与验证

```sh
docker compose up --build -d
docker compose exec -T app pytest -q
docker compose config --quiet
```

打开 http://localhost:18209 。点击“运行样例”，或展开输入区提交CSV。切换七个核算模块查看计算依据。复核区可通过或退回，同一版本仅允许一次复核。证据CSV包含所有阶段与隔离行，批次内容不因复核变更。

已通过复核的批次可在“撤销冲减”（/work/8）建立撤销决定：已付部分转应收、在途部分止付、未付部分终止支付，冲减额等于已复核应付额，原批次与客户已收凭证不变。同一撤销决定重跑复用原结果，不重复冲减；晚到付款只能追加事件，已确认结果不变。撤销证据单独导出，不并入批次证据CSV。

SQLite保存在命名卷records；容器重建保留历史。只在确认不再需要数据时执行 `docker compose down -v` 重建。端口可通过.env中的PORT调整。本地也可 `pip install -r requirements.txt` 后 `python -m app.main`。

## 定义与限制

详见docs/DATA-DICTIONARY.md、docs/DEPTH.md。单文件最大5MB/一万行，本工具按确定性文件离线复算，不查询外部业务系统。源码位于app，测试位于tests，样例位于sample_data。
